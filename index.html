1. Introdução

O aplicativo TrailTrekking respeita a privacidade dos usuários e foi desenvolvido com foco em segurança, transparência e uso offline.

Esta Política descreve como as informações são utilizadas durante o uso do App.

Ao utilizar o aplicativo, você concorda com estes termos.

2. Dados Utilizados

2.1 Dados de Localização (GPS)

Utilizados exclusivamente para:
- Registro da trilha (rota, distância, velocidade, altitude)
- Exibição da posição no mapa
- Cálculo de métricas (pace, calorias, desempenho)

✔ Funcionamento em segundo plano (necessário para trilhas reais)

Importante: Sem a permissão de localização em segundo plano, o app não consegue registrar a caminhada corretamente.

2.2 Uso de Inteligência Artificial (Gemini e Grok)

O aplicativo utiliza serviços de Inteligência Artificial para fornecer informações durante a caminhada.

Esses serviços podem receber:
- Localização aproximada (quando o usuário solicita)

Importante:
- Nenhum dado pessoal identificável é enviado
- As requisições são feitas apenas quando o usuário interage com a IA
- As respostas não são armazenadas em servidores próprios
- O app não controla o processamento feito pelos provedores de IA

2.3 Fotos da Caminhada

As fotos são tiradas pelo usuário dentro do app e armazenadas localmente no dispositivo.

Cada foto pode conter:
- Localização (latitude e longitude)
- Data e hora
- Nome definido pelo usuário

As imagens não são enviadas para servidores externos.

2.4 Dados de Perfil e Metas

Informações como peso, altura e metas são utilizadas apenas para cálculos internos.
Esses dados são armazenados localmente e nunca são compartilhados.

2.5 Contato de Emergência

Nome e telefone cadastrados pelo usuário são armazenados apenas no dispositivo.
Esses dados nunca são enviados ou compartilhados.

2.6 Dados de Trilhas

Incluem pontos GPS, distância, tempo e estatísticas da caminhada.
Todos os dados são armazenados localmente no dispositivo.

3. Dados NÃO Coletados

O TrailTrekking NÃO coleta:
- Nome ou e-mail
- Dados bancários
- Contatos do telefone
- Fotos pessoais externas ao app
- Histórico de navegação
- Dados para publicidade

4. Uso do Telefone (Emergência)

A permissão CALL_PHONE é utilizada para permitir ligações para contatos de emergência e serviços públicos.

O aplicativo nunca realiza chamadas automáticas. Todas as ações dependem do usuário.

5. Compartilhamento de Dados

Não há compartilhamento de dados com terceiros.
O aplicativo não utiliza servidores próprios, analytics ou publicidade.

6. Armazenamento e Segurança

Todos os dados são armazenados localmente no dispositivo.
Ao desinstalar o aplicativo, todos os dados são removidos.

7. Permissões Utilizadas

- Localização (precisa e em segundo plano)
- Serviço em primeiro plano
- Chamadas telefônicas
- Notificações
- Alarmes
- Internet (mapas e IA)

8. Menores de Idade

O aplicativo não é direcionado a menores de 13 anos.

9. Alterações

Esta política pode ser atualizada conforme melhorias no aplicativo.
