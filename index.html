POLÍTICA DE PRIVACIDADE

TrailTrekking — Aplicativo de Trilha e Trekking

Desenvolvedor: NBN10Developer (Narciso Brunazzo Neto)
Versão do App: 8.2.3
Última atualização: Maio de 2026

1. Introdução

O aplicativo TrailTrekking respeita a privacidade dos seus usuários e foi desenvolvido com foco em segurança, transparência e uso offline. Esta Política descreve como as informações são utilizadas durante o uso do App. Ao utilizar o aplicativo, você concorda com estes termos.

2. Dados Utilizados e Finalidade

2.1 Dados de Localização (GPS) — RECURSO CRÍTICO

O TrailTrekking coleta e processa dados de localização precisos para permitir as seguintes funcionalidades:

  • Registro detalhado da trilha (traçado da rota, distância total, velocidade atual e média, altitude).
  • Exibição da posição do usuário em tempo real sobre o mapa.
  • Cálculo de métricas de desempenho (pace, queima de calorias, tempo ativo).
  • Recurso de Pausa Automática, que detecta quando o usuário parou de se mover para suspender a gravação.
✔ Funcionamento em Segundo Plano:
O TrailTrekking coleta dados de localização para permitir o registro de suas trilhas e o recurso de pausa automática mesmo quando o aplicativo está fechado ou não está em uso. Este acesso é fundamental para a função principal do aplicativo. Sem a permissão de localização configurada como "Permitir o tempo todo", o registro do trajeto será interrompido sempre que você desligar a tela do dispositivo ou alternar para outro aplicativo.

2.2 Uso de Inteligência Artificial (Gemini e Groq)

O aplicativo utiliza serviços de Inteligência Artificial para fornecer informações contextuais e dicas de segurança.

  • Dados enviados: Apenas a localização aproximada e/ou comandos de voz/texto são enviados aos provedores de IA quando o usuário solicita explicitamente uma interação.
  • Privacidade: Nenhum dado pessoal identificável (nome, e-mail, documentos) é enviado. As respostas não são armazenadas em servidores do desenvolvedor.

2.3 Fotos da Caminhada

As fotos tiradas através do aplicativo são armazenadas exclusivamente de forma local no dispositivo do usuário. O aplicativo pode vincular a coordenada geográfica à foto para exibição no mapa interno, mas essas imagens nunca são enviadas para servidores externos ou para o desenvolvedor.

2.4 Dados de Perfil e Metas

Informações como peso, altura, idade e metas diárias são utilizadas apenas para cálculos matemáticos internos de IMC e gasto calórico. Esses dados são armazenados localmente e nunca são compartilhados.

2.5 Contatos de Emergência

Nomes e números de telefone cadastrados como "Contatos de Emergência" permanecem apenas na memória do dispositivo. O desenvolvedor não possui acesso a esses números.

3. Dados NÃO Coletados

O TrailTrekking mantém o compromisso de NÃO coletar:

  • Nomes reais ou endereços de e-mail.
  • Dados bancários ou informações de pagamento.
  • Lista completa de contatos do telefone.
  • Histórico de navegação na web.
  • Dados para fins publicitários ou marketing.

4. Uso do Telefone (Função SOS)

A permissão CALL_PHONE é utilizada exclusivamente para permitir que o usuário inicie chamadas para seus contatos de emergência ou serviços públicos (Polícia, Bombeiros) diretamente pela interface do app. O aplicativo nunca realiza chamadas automáticas ou sem o consentimento e ação manual do usuário.

5. Compartilhamento de Dados

Não há compartilhamento de dados com terceiros. O aplicativo não utiliza servidores próprios para armazenamento de dados de usuários, não possui ferramentas de analytics de terceiros nem exibe anúncios.

6. Armazenamento e Segurança

Todos os dados de trilhas e configurações são armazenados localmente no banco de dados interno do dispositivo (SQLite/Drift). Ao desinstalar o aplicativo, todos os dados são removidos permanentemente, a menos que o usuário tenha realizado um backup manual de seus arquivos de exportação (PDF/GPX).

7. Permissões Solicitadas

  • Localização (Precisa e em Segundo Plano): Para gravar o trajeto com precisão.
  • Serviço em Primeiro Plano (Foreground Service): Para manter o GPS ativo e visível na barra de notificações.
  • Chamadas Telefônicas: Para a função de emergência SOS.
  • Notificações e Alarmes: Para lembretes de metas e alertas de caminhada.
  • Câmera: Para capturar fotos durante a trilha.
  • Internet: Apenas para carregamento dos mapas e consultas à IA.

8. Menores de Idade

O aplicativo é adequado para todas as idades, mas não é direcionado especificamente a menores de 13 anos. Recomendamos que o uso por menores seja supervisionado por responsáveis.

9. Alterações nesta Política

Esta política pode ser atualizada periodicamente para refletir melhorias no aplicativo ou mudanças regulatórias. A data da última atualização será sempre exibida no topo desta página.
